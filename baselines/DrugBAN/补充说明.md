# DrugBAN 冷启动补充包（unseen_drug / unseen_target）

> 目的：让实验室电脑用 **DrugBAN** 跑 **BioSNAP 冷启动**（unseen_drug / unseen_target），与本地 SGBANDTI 的冷启动结果做公平对比。
> 数据 = SGBANDTI 同款 canonical 划分（SMILES, Protein, Y），与本地 SGBANDTI 完全一致（对比依据）。

## 一、解压到哪

本补充包需**覆盖到已解压的 `实验室_DrugBAN_GraphBAN` 包内**，即把 `DrugBAN-main/` 合并进去（覆盖 main.py，新增 datasets/biosnap/unseen_drug、unseen_target）：

```
实验室_DrugBAN_GraphBAN/
├── DrugBAN-main/
│   ├── main.py                     ← 用本包覆盖（已加 --split unseen_drug/unseen_target）
│   └── datasets/biosnap/
│       ├── unseen_drug/{train,val,test}.csv   ← 新增
│       └── unseen_target/{train,val,test}.csv ← 新增
```

> 环境/依赖沿用 `实验室运行说明_DrugBAN_GraphBAN.md` 里 DrugBAN 的环境，无需新增。

## 二、运行命令（5 种子，和 random 一样）

```bash
cd DrugBAN-main
# 药物冷启动（测试药物全未见）
python main.py --cfg configs/DrugBAN.yaml --data biosnap --split unseen_drug --seeds 42,52,62,72,82

# 靶标冷启动（测试蛋白全未见）
python main.py --cfg configs/DrugBAN.yaml --data biosnap --split unseen_target --seeds 42,52,62,72,82
```

- 配置同 random：batch 64、epoch 100、lr 5e-5（DrugBAN.yaml）
- 结果输出到 `DrugBAN-main/result/seed_{seed}/`
- 选优/阈值：与 random 一致（验证集选 best epoch；阈值依赖指标用 PR 曲线最优阈值，和修正后标准公式一致）

## 三、回传要求

每个 seed 跑完后：
1. 保存 **逐样本预测概率**（test 集的 y_true / y_prob），回传本机用于配对 bootstrap。
2. 回传每 seed 的 `result_metrics.pt` 或汇总（AUROC/AUPRC/F1/Sen/Spe/Acc）。

`datasets/biosnap/unseen_drug/{train,val,test}.csv`：
