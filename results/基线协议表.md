# 基线协议表（Baseline Protocol）

> 对应 P0-4：明确每个基线模型的代码来源、输入模态、种子、测试样本数与 AUPRC 口径。
> AUROC / AUPRC 均由统一脚本（`eval_metrics.py`，sklearn `roc_auc_score` / `average_precision_score`）按同一逐样本预测重算；
> 阈值依赖指标（F1/Sens/Spe/Acc）统一使用验证集 F1 最优阈值。种子统一为 42, 52, 62, 72, 82。
> 测试样本数 = 各数据集 test 子集（BioSNAP random 5,491；BindingDB 9,840；unseen-drug 5,290；unseen-target 4,903）。

| 基线 | 官方仓库 | 本仓库复现路径 | 输入模态 | 代码版本（尽力可追溯） | 种子 | AUPRC 口径 |
|---|---|---|---|---|---|---|
| SGBANDTI（Ours） | — | `code/` | 分子图 rooted-subgraph + 蛋白序列 CNN | 本仓库 | 42–82 | sklearn average_precision_score |
| DrugBAN | github.com/peizhenbai/DrugBAN | `baselines/DrugBAN/` | 2D 分子图 + 蛋白序列（双线性注意力 BAN，无域适应 Non_DA） | 上游 commit `9923f8c`（2023-02-19）+ 本文适配 patch `baselines/DrugBAN/patches/drugban_adaptation.patch` | 42–82 | 统一重算 |
| MolTrans | github.com/kc-chenlab/MolTrans | `baselines/MolTrans/` | substructure embedding + 蛋白序列 | 拷贝未固定 commit | 42–82 | 统一重算 |
| MGNDTI | github.com/Nicole-cui/MGNDTI | `baselines/MGNDTI/` | 多模态（分子图 + 序列 + 特征） | 拷贝未固定 commit | 42–82 | 统一重算 |
| iNGNN-DTI | github.com/CSUBioGroup/iNGNN-DTI | `baselines/INGNN/` | nested GNN + 蛋白序列 | 拷贝未固定 commit | 42–82 | 统一重算 |
| TransformerCPI | github.com/lucian02/TransformerCPI | `baselines/TransformerCPI/` | SMILES 序列 + 蛋白序列 | 拷贝未固定 commit | 42–82 | 统一重算 |
| GNN-CPI | github.com/IBM/Interpretable-… (CPI, Tsubaki et al.) | `baselines/GNN-CPI/` | 分子图 + 蛋白序列 CNN | 拷贝未固定 commit | 42–82 | 统一重算 |
| RF | 自实现 | `baselines/RF/` | RDKit 分子特征 + 蛋白特征 | 自实现，未固定版本 | 42–82 | 统一重算 |

> **可追溯性说明**：各基线均为官方仓库拷贝（RF 为自实现）。**DrugBAN 已固定上游 commit `9923f8c99959e00263103ff9ac61ba0eaccc8e02` 并附本文适配 patch**（详见 `baselines/DrugBAN/EVIDENCE.md`）；其余基线的 commit 仍未固定。
> 严格复现如需逐版本可追溯，应为其余基线补记官方 release/commit 标识或下载日期。
>
> **逐样本可得性（P0-1）**：已归档**逐样本预测**（`stats_input/`，AUROC/AUPRC 由统一脚本从逐样本重算）的有 **SGBANDTI、DrugBAN（4 个划分）、MGNDTI（4 个划分）、RF（4 个划分）、MolTrans（BindingDB random + BioSNAP unseen_drug）**；仅归档**逐种子**的有 **TransformerCPI（BindingDB random）、GNN-CPI（BindingDB random）**；**仍有 12 行仅有 mean±SD**，其逐种子/逐样本当年未保存，逐行来源标注见 `results_manifest.csv` 的 `source` 列（BioSNAP random：MolTrans / INGNN / TransformerCPI / GNN-CPI；BindingDB random：INGNN；BioSNAP unseen_drug：TransformerCPI / INGNN / GNN-CPI；BioSNAP unseen_target：MolTrans / INGNN / GNN-CPI / TransformerCPI）。阈值依赖指标（F1/Sens/Spe/Acc）仅对 SGBANDTI 采用验证集选优阈值，不用于跨模型主排名。
