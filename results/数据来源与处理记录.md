# SGBANDTI 数据来源与处理记录（Data Provenance）

> 对应 P0-3：一次性、准确地披露 processed benchmark 的来源、处理管线、哈希，以及不可追溯项（归因于上游 benchmark，而非笼统"released files do not reconstruct"）。
> 本仓库固定提交：git tag `v1.0.0-paper`（本地 commit，可核对）。

## 一、数据来源

| 数据集 | 原始数据库 | 官方下载入口 | 直接上游来源 | 本文所用的数据 |
|---|---|---|---|---|
| BindingDB | Liu et al., 2007 | https://www.bindingdb.org/rwd/bind/downloads/ （月度发布，`BindingDB_All_<YYYYMM>_tsv.zip`） | **DrugBAN（Bai et al., 2023）公开代码仓库** | processed 二分类 benchmark（train/val/test CSV，Y∈{0,1}） |
| BioSNAP | Zitnik, Sosič & Leskovec, 2018 | http://snap.stanford.edu/biodata （Drug–target interaction network） | **iNGNN-DTI（Sun et al., 2024）公开代码仓库** | processed 二分类 benchmark（random / unseen-drug / unseen-target，Y∈{0,1}） |

- 本文使用的 **processed 文件**（`SMILES, Protein, Y`）取自上述两篇论文的公开代码仓库所附带的 DTI 二分类处理数据，**不是**从 BindingDB/BioSNAP 原始数据库重新生成。
- **获取方式**：由上游同学从 DrugBAN / iNGNN-DTI 代码仓库取得后提供（本仓库拷贝取得），**非本人从官方站点下载**；原始 BindingDB/BioSNAP 下载的 release 版本与日期由上述两篇论文的作者处理，不可从本仓库追溯，归因于上游（见第四节）。
- **来源验证（2026-08-31）**：已核对两个公开代码仓库——`github.com/peizhenbai/DrugBAN` 与 `github.com/CSUBioGroup/iNGNN-DTI` 均含 BindingDB（train 34,439）与 BioSNAP random（train 19,220）的 processed 数据，样本数与本文 `SPLITS_FROZEN` 完全一致；iNGNN 另含一个 cold split（19,225），本文未使用。指纹（样本数）吻合，可核验。
- 生物医学资源许可：BindingDB（CC-BY 系列）、BioSNAP（Stanford SNAP 数据集页面，注明访问日期）。

## 二、处理管线（可复现部分）

1. **SMILES 解析与规范化**：RDKit 解析，失败记录剔除；成功记录转 **RDKit-canonical SMILES**。
2. **去重与标签冲突**：以 canonical SMILES + 大写蛋白序列为 pair 标识去重；**BioSNAP 去重 7 对**；冲突标签保留正类。
3. **划分**：去重后 7:1:2（train/val/test），seed 42，无类别分层采样；实体（药物/蛋白）可跨子集出现（random），或按 canonical SMILES / 蛋白序列完全不相交（unseen-drug / unseen-target）。
4. **脚本**：`build_splits.py`（划分）、`build_subgraph_cache.py`（子图缓存）；冻结记录 `SPLITS_FROZEN.md/json`。

## 四、不可追溯项（一次性归因于上游）

以下信息属于**上游 benchmark 的数据生成过程**，本文的 processed 文件未随文件归档这些细节，无法独立重建：

| 项 | 状态 |
|---|---|
| BindingDB 具体 release 版本 / 下载日期 | **未归档**（官方月度发布 `BindingDB_All_<YYYYMM>_tsv.zip`；原始下载由 DrugBAN 论文作者完成，本仓库无法追溯具体月份） |
| affinity-to-binary 转换规则（阈值/单位归一化） | **未归档**（processed 文件继承自 DrugBAN 的处理协议） |
| BindingDB 负样本构建方式 | **未归档**（同上） |
| BioSNAP 快照日期 | **未归档**（原始快照由 iNGNN-DTI 论文作者获取，本仓库无法追溯） |
| BioSNAP unlabeled 对采样规则（0 标签来源） | **未归档**（同上） |

> 处理方式：0 标签按 **benchmark negative / unobserved pair** 解释，不视为实验验证的非结合对；本限制需在数据可用性说明中一次性披露、不四处重复。
